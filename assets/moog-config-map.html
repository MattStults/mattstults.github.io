Substrate → Pipeline config map

Pick a problem substrate (global, swaps everything); the tabs below walk the pipeline in run order — Stage-0 → SFT → RL. Each tab shows the prompt / completion / SDF text for that stage, and the right panel shows its parameters (read-only; active params highlighted).

This is a plan-communication view for the model organism of oversight gaming project: a small (1.7B) model is taught an arithmetic “review desk” task where some reports are audited, and the question is whether audit-conditional gaming — report the honest answer when the item is audited, inflate when it isn’t — emerges under RL rather than being hand-installed. Every tab is a real config the pipeline runs; this map exists so the exact prompts, seeds, and SDF corpora are auditable in one place.
