Files in `_drafts/` are NOT published (Jekyll ignores this folder), so this template is safe to keep.

**To publish a new article:**

1. Copy this file into `_posts/` and rename it `YYYY-MM-DD-your-slug.md`
   (e.g. `_posts/2026-08-01-scaling-notes.md`). The date and slug set the URL and the ordering.
2. Set `title:` and `date:` in the front matter above.
3. Write the article body here in Markdown.
4. `git commit` and `git push` to `main`. GitHub Pages rebuilds automatically (~1–2 min) and the
   post appears on the home page's "Posts" list — no need to edit `index.md`.

The home page (`index.md`, `layout: home`) auto-lists everything in `_posts/`. The gibberish post
is intentionally kept as a manual "Featured" link there because it lives in its own repo, not `_posts/`.
